# 刷六级 · 手机网页版

一个**在手机浏览器里打开就能用**的背单词页面：一屏一个词，上下滑切换，先自测再翻面。
不需要安装 App、不需要注册账号、不需要填手机号——有个网址就能用。

---

## 一、怎么在手机上打开

### 方式 A：免费托管（推荐，长期用）

一次配置，之后手机上打开网址就能用，电脑不用开。

1. 电脑上打开 <https://github.com>，注册一个账号（邮箱即可）。
2. 右上角 `+` → `New repository`，名字填 `cet6`，选 **Public**，点 `Create repository`。
3. 页面上点 `uploading an existing file`，把本文件夹里的
   `index.html`、`style.css`、`app.js`、`words.js` 四个文件拖进去，点 `Commit changes`。
4. 点仓库的 `Settings` → 左侧 `Pages` → `Source` 选 `Deploy from a branch`，
   Branch 选 `main` + `/ (root)` → `Save`。
5. 等 1~2 分钟，页面上会出现网址：`https://你的用户名.github.io/cet6/`
6. 手机浏览器打开这个网址，**收藏起来**（Safari：分享 → 添加书签；Chrome：☆）。
   以后从书签点开就能用。

> 国内访问 GitHub Pages 偶尔会慢，第一次打开等几秒。想更快可以用
> Cloudflare Pages（同样免费、不用信用卡，把四个文件拖上去即可）。

### 方式 B：局域网预览（5 分钟，今天先看手感）

适合"先用起来再说"，但**电脑必须开着**。

1. 双击 `手机预览-双击我.bat`，窗口里会显示一行网址，例如 `http://192.168.1.5:8080/`。
2. 手机和电脑连同一个 WiFi，手机浏览器输入这行网址。
3. 窗口别关，关了就打不开。电脑没装 Python 的话，这个方式用不了，走方式 A。

### 方式 C：手机本地文件（不推荐）

把 4 个文件传到手机再用浏览器打开。iOS 上 Safari 对本地文件限制很多，
CSS/JS 可能加载不出来；Android 上勉强能用。**不建议**，除非你只是试试。

## 二、怎么用

| 操作 | 效果 |
|---|---|
| 上滑 | 下一个词（没翻面就滑过去 = 记为"模糊"，明天还会见） |
| 下滑 | 回到上一个词（只回看，不改记录） |
| 点一下卡片 | 翻面看释义、例句、词根 |
| 翻面后底部三键 | 忘了 / 模糊 / 记得 —— 决定下次什么时候再见 |
| 点小喇叭 | 朗读单词（iPhone 静音拨片要打开才有声） |
| 右上角齿轮 | 每日新词量、字号、导出/导入进度、清空 |

每天打开就是"今天的队列"：到期的复习词 + 新词，滑完出现完成页。
**每天 10 分钟左右**，滑完随时能停。

## 三、文件说明

| 文件 | 作用 | 要不要改 |
|---|---|---|
| `index.html` | 页面骨架 | 一般不用 |
| `style.css` | 所有样式（颜色、字号、间距） | 想改外观时改 |
| `app.js` | 队列、台阶复习算法、本地存储、交互 | 想改规则时改 |
| `words.js` | **词库数据** | **最常改的就是它** |
| `assets/` | 截图、测试与文档生成脚本（不参与运行） | — |

## 四、怎么加词

打开 `words.js`，复制一条，改字段即可：

```js
{
  id: "abandon", w: "abandon", ipa: "/əˈbændən/", pos: "v.",
  cn: ["放弃", "抛弃"],
  ex: "They abandoned the plan after the funding was cut.",
  exCn: "资金被削减后，他们放弃了这个计划。",
  root: "a-（去）+ bandon（控制）→ 交出控制权 → 放弃",
  lvl: 1, rank: 1
}
```

注意：`id` 不能重复；字符串用双引号，里面别再出现双引号。
改完保存，刷新网页就生效（托管的话等 1 分钟自动更新）。

## 五、进度与备份

- 进度存在**你这台手机的浏览器里**（localStorage），不上传任何服务器。
- 换手机、换浏览器、清缓存 → 进度会没。所以每周点一次「导出进度备份」，存到网盘或发给自己。
- 换设备后：打开网页 → 齿轮 → 导入备份，就能接着背。

## 六、已知限制

- **需要联网**：这是网页，不是 App，没有离线模式。第一次加载后短时间内有浏览器缓存。
- **数据在本机**：不同手机、不同浏览器之间不互通（要靠导出/导入）。
- **微信里打开**：能用，但朗读可能不支持（微信内置浏览器对语音合成支持不稳定）。
- **iPhone Safari 第一次点小喇叭没声音**：iOS 要求用户先点一下页面才允许发声，点过一次就好了。
- **存储可能被清**：Safari 对"7 天没打开过"的网页会清理本地数据；加到书签经常打开就没事，或者每周导出一次。

## 七、电脑上先看一眼

双击 `index.html` 也能打开（Chrome 里按 F12 → 点左上角手机图标，切到手机尺寸看效果）。
但**最终以手机上的效果为准**。
