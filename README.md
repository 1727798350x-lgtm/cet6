# 刷六级 · 手机网页版

一个**在手机浏览器里打开就能用**的背单词页面：一屏一个六级考纲词，单词、音标、释义、例句、相关词一起显示，上下滑切换。

不需要安装 App、不需要注册账号——有个网址就能用。

**网址：<https://1727798350x-lgtm.github.io/cet6/>**

---

## 一、怎么在手机上打开

### 方式 A：直接用线上网址（推荐）

手机浏览器打开上面的网址，**加书签**：
- iPhone Safari：底部「分享」→「添加书签」→ 存到「个人收藏」
- Android Chrome：地址栏右侧「☆」→ 完成

以后点书签就能刷。电脑不用开。

> 第一次打开可能慢几秒（词库约 800KB，GitHub 服务器在国外），之后有缓存会快。
> 微信里也能打开，但朗读可能没声音，建议用系统浏览器。

### 方式 B：局域网预览（改代码后马上看效果）

1. 双击 `手机预览-双击我.bat`，窗口里会显示一行网址，例如 `http://192.168.1.5:8080/`
2. 手机和电脑连同一个 WiFi，手机浏览器输入这行网址
3. 窗口别关，关了就打不开；电脑没装 Python 的话这个方式用不了

## 二、怎么用

| 操作 | 效果 |
|---|---|
| **上滑** | 下一个词（单纯翻页，**不记录学习状态**） |
| **下滑** | 回到上一个词 |
| **☆ / ★** | 收藏／取消收藏，收藏的词进「收藏夹」 |
| 底部三键 | 忘了 / 模糊 / 记得 —— **只有点按钮才会被记为学过** |
| 点小喇叭 | 朗读单词（iPhone 静音拨片要打开才有声） |
| 右上角齿轮 | 每日新词量、字号、收藏夹、导出/导入进度、清空 |

### 几个关键规则

- **滑过去不算**：上滑只是换词，不产生任何学习记录。点了「忘了/模糊/记得」才算学过，才会进入复习计划。
- **断点续刷**：下次打开会从你上次刷到的位置继续，不会每次都从头来。
- **每日新词默认不限**：想给自己定量，在设置里选 10 / 20 / 40。
- **收藏夹**：设置 →「收藏夹」→ 只刷你收藏过的词；左上角「← 回到今天」返回。

### 每张卡上有什么

- 单词、音标、词性、中文释义
- 例句 + 译文（部分词有）
- 词根 / 助记（部分词有）
- **相关词**：派生（同词族的其他形式）、同义（释义相同的词）、形近（拼写相近的词）

## 四、怎么加词

打开 `words.js`，复制一行，改字段即可：

```js
  {id:"abandon", w:"abandon", ipa:"/əˈbændən/", pos:"v.", cn:["放弃","抛弃"],
   fam:["abandoned","abandoning","abandons"], sim:["abundant","abandon"],
   ex:"They abandoned the plan after the funding was cut.", exCn:"资金被削减后，他们放弃了这个计划。",
   root:"a-（去）+ bandon（控制）→ 交出控制权 → 放弃", lvl:1, rank:1},
```

- `id` 不能重复，一般就用单词小写
- `cn` 释义数组，1–3 条；`fam` 派生；`sim` 形近
- `ex` / `exCn` / `root` 可以留空
- `rank` 决定顺序

改完保存，刷新网页就生效。线上版：GitHub 网页打开 `words.js` → 编辑 → Commit，1 分钟后手机刷新就是新的。

## 五、进度与备份

- 进度（学习状态 + 收藏）存在**你这台手机的浏览器里**（localStorage），不上传任何服务器。
- 换手机、换浏览器、清缓存 → 进度会没。每周点一次「导出进度备份」。
- 换设备后：打开网页 → 齿轮 → 导入备份。

## 六、已知限制

- **需要联网**：网页版没有离线模式；词库约 800KB，第一次打开要多等一会儿。
- **数据在本机**：不同手机、不同浏览器之间不互通（靠导出/导入）。
- **微信里**：能用，但朗读可能没声音；下拉会刷新页面。
- **iPhone 第一次点小喇叭没声音**：iOS 要求先点一下页面才允许发声。
- **同义/形近是算出来的**：同义来自释义相同，形近来自编辑距离，偶尔有噪音（比如把 `despite` 归到"憎恨"那一组），当提示看就好。
- **手机性能**：一口气刷几百张时页面元素会越积越多，觉得卡了刷新一下即可（进度不会丢）。
