# 刷六级 · 手机网页版

一个**在手机浏览器里打开就能用**的背单词页面：一屏一个六级核心词，单词、音标、释义、例句一起显示，上下滑切换，底部三键记一下"忘了 / 模糊 / 记得"，系统自动安排下次什么时候再出现。

不需要安装 App、不需要注册账号——有个网址就能用。

**网址：<https://1727798350x-lgtm.github.io/cet6/>**

---

## 一、怎么在手机上打开

### 方式 A：直接用线上网址（推荐）

手机浏览器打开上面的网址，**加书签**：
- iPhone Safari：底部「分享」→「添加书签」→ 存到「个人收藏」
- Android Chrome：地址栏右侧「☆」→ 完成

以后点书签就能刷。电脑不用开。

> 第一次打开可能慢几秒（GitHub 服务器在国外），之后有缓存会快。
> 微信里也能打开，但朗读可能没声音，建议用系统浏览器。

### 方式 B：局域网预览（5 分钟，改代码后马上看效果）

1. 双击 `手机预览-双击我.bat`，窗口里会显示一行网址，例如 `http://192.168.1.5:8080/`
2. 手机和电脑连同一个 WiFi，手机浏览器输入这行网址
3. 窗口别关，关了就打不开；电脑没装 Python 的话这个方式用不了

## 二、怎么用

| 操作 | 效果 |
|---|---|
| **上滑** | 下一个词 |
| **下滑** | 回到上一个词（只回看，不改记录） |
| 底部三键 | 忘了 / 模糊 / 记得 —— 决定这个词下次什么时候再出现 |
| 点小喇叭 | 朗读单词（iPhone 静音拨片要打开才有声） |
| 右上角齿轮 | 每日新词量、字号、导出/导入进度、清空 |

**卡片直接显示单词和释义，不需要点。** 每张卡按 1.5–2 秒的节奏刷就行。

- **上滑但不评分** = 自动记为「模糊」，明天还会见到它。
- **每日新词默认不限**：词库里的词会一直往后刷；想给自己定量，在设置里选 10 / 20 / 40。
- 顶部显示「已刷 N 张」，进度条按 200 张填满，只是激励，不是上限。

## 四、怎么加词

打开 `words.js`，复制一行，改字段即可：

```js
  {id:"abandon", w:"abandon", ipa:"/əˈbændən/", pos:"v.", cn:["放弃","抛弃"],
   ex:"They abandoned the plan after the funding was cut.", exCn:"资金被削减后，他们放弃了这个计划。",
   root:"a-（去）+ bandon（控制）→ 交出控制权 → 放弃", lvl:1, rank:1},
```

- `id` 不能重复，一般就用单词小写
- `cn` 是释义数组，1–3 条
- `ex` / `exCn` / `root` 可以留空
- `rank` 决定顺序，重复没关系（数字小的先出现）

改完保存，刷新网页就生效。线上版改法：GitHub 网页打开 `words.js` → 编辑 → Commit，1 分钟后手机刷新就是新的。

## 五、进度与备份

- 进度存在**你这台手机的浏览器里**（localStorage），不上传任何服务器。
- 换手机、换浏览器、清缓存 → 进度会没。每周点一次「导出进度备份」存到网盘或发给自己。
- 换设备后：打开网页 → 齿轮 → 导入备份。

## 六、已知限制

- **需要联网**：网页版没有离线模式。
- **数据在本机**：不同手机、不同浏览器之间不互通（靠导出/导入）。
- **微信里**：能用，但朗读可能没声音；下拉会刷新页面。
- **iPhone 第一次点小喇叭没声音**：iOS 要求先点一下页面才允许发声。
- **上滑不评分会自动记「模糊」**：刷得越多，第二天的复习越多——这是间隔重复在正常工作。
